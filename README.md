# Curioverse

The live gallery is [xstaryt.github.io](https://xstaryt.github.io/). GitHub Pages publishes this repository's `main` branch from the repository root.

This is a static site with no build step. `index.html` is the gallery; `quantum.html`, `quantum.css`, and `quantum.js` form the quantum computing exhibit. Keep links and asset paths relative so every exhibit works from GitHub Pages.

Changes pushed to `main` are published automatically by GitHub Pages. See [GitHub's Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
